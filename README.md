# B&B — «Первый шаг»

«Первый шаг» — карьерный навигатор команды B&B для выпускников, которые ищут первую работу или осваиваются на новом месте.

## Что есть в навигаторе

- Подготовка резюме, ответов на вопросы работодателя и рассказа о себе.
- План адаптации на первой работе, дневник достижений и материалы для рабочих разговоров.

## Как открыть проект

Скачайте репозиторий и откройте [`career-guide/index.html`](career-guide/index.html) в браузере. Для просмотра страницы сборка и установка зависимостей не нужны.

HTML, стили и скрипты страницы находятся в `career-guide/index.html`.
