# B&B — «Новая глава»

«Новая глава» — карьерный навигатор команды B&B. Он помогает подготовиться к поиску работы, освоиться на новом месте и разобраться в трудовых правах.

## Что есть в навигаторе

- Поиск работы после учёбы, смены профессии или перерыва. В разделе есть материалы по резюме и собеседованиям.
- Адаптация на новой работе. Здесь собраны материалы по первым рабочим задачам и общению с командой.
- Права работника, трудовые документы и ссылки на источники.

## Как открыть проект

Скачайте репозиторий и откройте [`career-guide/index.html`](career-guide/index.html) в браузере. Для просмотра сайта сборка и установка зависимостей не нужны.

Ветка `main` автоматически синхронизируется из GitHub в SourceCraft через GitHub Actions.
