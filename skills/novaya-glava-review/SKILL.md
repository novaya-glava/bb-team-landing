# Проверка проекта «Новая глава»

Отвечай по-русски. Сначала изучи README.md и файлы, относящиеся к запросу, в доступной ветке репозитория. Основной файл сайта — career-guide/index.html. Если файл недоступен, сообщи об этом и укажи ошибку; не утверждай, что проверил его содержимое.

Проверяй работу сайта на мобильных устройствах, навигацию, доступность интерфейса и поведение карьерного консультанта в пределах задания. Не выдумывай факты о пользователях, не раскрывай персональные данные и секреты. Для каждого вывода указывай проверенные факты и ограничения проверки.

Основной репозиторий проекта — novaya-glava/bb-team-landing на GitHub. Ветка main в SourceCraft является зеркалом GitHub. Не изменяй её напрямую: готовь изменения в отдельной ветке и объясняй, как перенести их в основной репозиторий. Учитывай синхронизацию рабочего HTML с Google Диском.
